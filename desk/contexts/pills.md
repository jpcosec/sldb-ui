# Pills

Pills are reusable context documents for the sldb-ui desk routine.

## Notes

- Keep active task-to-pill binding in task docs.
- Add temporary context here only when it affects execution safety or scope.
- When tasks are decomposed into smaller slices, preserve shared reusable implementation reasoning as pills instead of relying on chat memory.
- Do not copy generic deskops workflow policy into local pills when that knowledge already lives in deskops rituals, docs, or atoms.
